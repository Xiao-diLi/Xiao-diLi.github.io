# Publications

Add your publications here as Markdown files. Each file should follow this naming convention:

```
YYYY-MM-DD-short-title.md
```

## Template

```markdown
---
title: "Your Paper Title"
collection: publications
category: manuscripts
permalink: /publication/YYYY-short-title
excerpt: 'Brief description of the paper.'
date: YYYY-MM-DD
venue: 'Journal or Conference Name'
paperurl: 'https://link-to-paper'
citation: 'Author1, Author2. (Year). "Title." <i>Journal</i>. Vol(Issue), Pages.'
---

Optional longer description of the paper.
```

### Category options
- `manuscripts` — Journal articles
- `conferences` — Conference papers
- `books` — Books or book chapters

You can also use the `markdown_generator/` tool to batch-generate publication files from a TSV or BibTeX source.
